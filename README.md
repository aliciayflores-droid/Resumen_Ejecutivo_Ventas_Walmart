# Título del Proyecto:
*Resumen Ejecutivo de Ventas Walmart*
## Contexto del Problema:
*Determinar las categorías de departamento que tuvieron mayor eficiencia para generar ventas y el potencial de cada departamento.*
## Herramientas Utilizadas:
*Excel Avanzado, Tablas Dinámicas, Fórmulas Avanzadas (XLOOKUP/SUMIFS), Dashboards Ejecutivos, Limpieza de Datos*
## Metodología y Proceso:
*1) Limpieza y preparación de los datasets para analisis
2) Integración de tablas y generación de tablas dinámicas con KPIs principales
3) Generación de Dashboard con filtros y visulaciones
4) Realización de Resumen e informe con validaciones de calidad*
## Principales Hallazgos:
*El departamento de Despensa y básicos tiene ventas por metro cuadrado = $82.88
Hay 4 departamentos con participación menor a 5% (Cuidado de Mascotas, Jardín y Vida al Aire Libre,bJuguetes y Juegos,Oficina, Escuela y Manualidades)
Se sugiere priorizar inventario y distribución de recursos para el departamento de Despensa y básicos, así cómo analizar el inventario y estrategias de visibilización del departamento*
